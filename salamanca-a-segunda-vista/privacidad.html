Política de privacidad

Salamanca a segunda vista utiliza los servicios de la API de YouTube para gestionar el canal del estudio. Esta política explica qué datos recibe la aplicación de escritorio y qué ocurre cuando su titular aprueba un envío.

Datos del canal y finalidad

  • Identidad y acceso. Google entrega un permiso de acceso y una credencial de renovación. La aplicación comprueba el identificador público, el nombre y el ID del canal para dirigir los envíos a la cuenta correcta. El titular introduce sus credenciales en Google.
  • Vídeos y publicaciones. Al ejecutar una autorización editorial, la aplicación envía a YouTube el archivo aprobado, el título, la descripción, los créditos, las etiquetas y la visibilidad. También gestiona los subtítulos y, en los documentales, la miniatura. Consulta a YouTube los identificadores, las fechas y el estado de los envíos para confirmarlos y reanudar una operación interrumpida.
  • Estadísticas. Para evaluar sus publicaciones, el estudio consulta en YouTube Analytics el número de reproducciones, los minutos vistos, el porcentaje medio visto y las suscripciones ganadas. Son cifras agregadas por vídeo. La mesa de producción las usa para comparar temas y formatos.

Quién recibe los datos

Google tramita el consentimiento y YouTube recibe las publicaciones autorizadas. La visibilidad que el titular apruebe determina quién podrá ver el vídeo en YouTube. El titular y los agentes de producción que designe pueden consultar el registro editorial y las métricas cuando trabajan en el estudio. Las demás redes tienen conexiones y autorizaciones independientes.

El uso y la transferencia de la información recibida de las API de Google se limitan a las funciones descritas en esta política y se rigen por la Política de Datos de Usuario de los Servicios API de Google, incluidos sus requisitos de uso limitado. Política de datos de las API de Google.

Dónde se guardan

La aplicación cifra la sesión de Google con la protección de datos de Windows, vinculada al usuario del equipo. Los identificadores, estados, decisiones y estadísticas se conservan en archivos y en una base de datos SQLite de la mesa de producción. Las copias que haga el titular del proyecto pueden contener esos registros.

Retirar el permiso o pedir la supresión

El titular puede abrir las conexiones de su cuenta de Google, seleccionar la aplicación del estudio y retirar su acceso. YouTube Studio permite gestionar por separado los vídeos que ya se enviaron. Gestionar las conexiones de mi cuenta de Google.

Para eliminar la sesión guardada, los datos de YouTube del registro local y las copias bajo su control, el titular puede pedir la supresión a Dirección en su canal de trabajo con el estudio. Para consultas, reclamaciones o solicitudes de supresión también puede escribir al correo de asistencia que figura en la pantalla de consentimiento de Google de esta aplicación.

Visitas a esta web

Estas páginas son informativas y se sirven como archivos estáticos. El alojamiento puede procesar la dirección IP y las solicitudes HTTP para entregarlas. La web no incorpora formularios, herramientas de seguimiento ni vídeos de terceros. Los enlaces a Google y YouTube abren sus propios servicios. Política de privacidad de Google.
